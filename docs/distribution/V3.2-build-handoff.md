## Golden corpus and vendor status

The measured baseline is [the empty corpus report](evidence/native-corpus-baseline.json): the 3 October qualification run had no reviewed corpus, quality values are null, and release approval is false. The owner subsequently supplied one Telugu source for the [Episode 249 local content test](Episode-249-content-acceptance.md); it remains unreviewed and does not advance corpus qualification. A qualifying corpus requires 20 distinct Telugu, five Kannada and five Tamil recordings, with 3–5 independently marked reference moments per video and authorized language reviewers. Synthetic fixtures and repeated source checksums cannot qualify.

The evaluation harness reports acceptance without meaning correction, teaching recall, boundary precision, context/negation safety, terminology errors, translation fidelity, framing, reviewer edits and time saved separately. It never grants release approval.

The OpenAI adapter follows the official [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs) contract and sends `store:false`. [OpenAI data controls](https://developers.openai.com/api/docs/guides/your-data) still require a separate retention assessment; `store:false` is not a claim of zero data retention. No model, provider account or contract has been adopted by this build.
